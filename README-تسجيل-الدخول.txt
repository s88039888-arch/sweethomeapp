تحديث Sweet Home — تسجيل الدخول الآمن

ما تم تغييره:
1) حذف كلمة المرور الافتراضية admin123 من واجهة لوحة الإدارة.
2) إزالة نظام كلمة المرور المحلية من لوحة الإدارة.
3) الموقع الآن يطلب تسجيل الدخول بالبريد الإلكتروني وكلمة المرور عبر Firebase Authentication قبل دخول الموقع.
4) لوحة الإدارة تطلب البريد الإلكتروني وكلمة المرور، ثم تتحقق من صلاحية المدير عبر Firestore.
5) تمت إضافة «نسيت كلمة المرور؟» إلى صفحة login.html لإرسال رابط إعادة التعيين بالبريد.

الملفات المعدلة:
- index.html
- login.html
- app.js

إعداد حساب المدير:
1) افتح Firebase Console > Authentication > Users.
2) أنشئ حساب المدير بالبريد الإلكتروني وكلمة المرور.
3) انسخ UID الخاص بحساب المدير.
4) افتح Firestore Database.
5) أنشئ/افتح collection باسم: users
6) أنشئ document باسم UID الخاص بالمدير.
7) أضف الحقل:
   role = admin

يمكن أيضًا استخدام:
   isAdmin = true

مهم:
- كل العملاء يمكنهم إنشاء حساباتهم وتسجيل الدخول من login.html.
- العميل العادي يستطيع دخول الموقع، لكنه لا يستطيع فتح لوحة الإدارة.
- لا تضع كلمة مرور المدير داخل HTML أو JavaScript.
- من الأفضل لاحقًا ضبط Firestore Security Rules حتى تكون صلاحية المدير محمية على مستوى قاعدة البيانات أيضًا، وليس فقط على واجهة الموقع.

بعد استبدال الملفات الثلاثة على GitHub:
- افتح الموقع.
- إذا لم تكن مسجلًا، سيحولك تلقائيًا إلى login.html.
- سجل حساب عميل عادي للتجربة.
- جرّب لوحة الإدارة بحساب المدير الذي role=admin.
