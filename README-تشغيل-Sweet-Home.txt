Sweet Home — ملفات المشروع المحدثة

المحتويات:
- index.html و app.js: واجهة التطبيق ومنطق المتجر.
- data.json: بيانات عامة مشتركة للمنتجات والفروع والأسعار، بدون كلمة مرور الإدارة أو الطلبات.
- manifest.json و sw.js: إعدادات PWA والتخزين المؤقت.
- logo.png و icon-192.png و icon-512.png و icon-maskable-512.png: الصور المطلوبة.
- privacy.html و delete-account.html: سياسة الخصوصية وحذف الحساب.
- firestore.rules.txt: قواعد Firestore الحالية.

طريقة الرفع:
1) ارفع كل الملفات الموجودة في هذا المجلد إلى جذر مستودع GitHub Pages، مع استبدال الملفات القديمة.
2) تأكد أن GitHub Pages مفعّل من Settings > Pages.
3) افتح رابط الموقع عبر HTTPS. حدّث الصفحة أو امسح بيانات الموقع إذا استمرت نسخة قديمة بسبب التخزين المؤقت.

تنبيه مهم قبل النشر على Google Play:
هذه نسخة ويب/PWA وليست ملف APK أو AAB جاهزًا. كما أن كلمة مرور لوحة الإدارة الافتراضية والتحقق منها ما زالا داخل app.js، وسجل الطلبات ونقاط الولاء محليان على جهاز العميل؛ إرسال الطلب يتم عبر فتح WhatsApp وليس حفظه في قاعدة بيانات مشتركة. لا تستخدمها لإدارة طلبات حقيقية أو تعتبرها جاهزة للنشر قبل نقل صلاحيات الإدارة والطلبات إلى خادم/قواعد Firebase آمنة واختبارها.
